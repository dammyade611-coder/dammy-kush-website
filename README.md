# DAMMY KUSH DESIGN — Website

A responsive static portfolio website using HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For a local development server, you can use VS Code's Live Server extension.

## Before publishing
- Confirm the contact details and social links in `index.html` and `script.js`.
- Replace the illustrative portfolio tiles with your actual projects.
- Replace the banner-based logo crop with a transparent, high-resolution logo file if available.
- The enquiry form opens a pre-filled WhatsApp message. It does not store submissions in a database.
- Review the Google Fonts import in `styles.css`; local/system fallbacks are provided if fonts do not load.

## Deploy
You can import the project into a GitHub repository and deploy it as a static site using GitHub Pages, or deploy the repository through a static hosting provider such as Vercel. A custom domain can be connected later.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive dark/blue/purple/gold visual design
- `script.js` — mobile menu and WhatsApp enquiry form
- `assets/` — uploaded banner and cropped brand lockup
